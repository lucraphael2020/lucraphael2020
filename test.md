## 🔬 Labs and Projects | Labs et projets

### 🏗️ Active Directory Lab
Hybrid and multi-forest Active Directory lab designed to simulate enterprise administration scenarios.  
Lab Active Directory hybride et multi-forêts conçu pour simuler des scénarios d’administration en environnement d’entreprise.

- DC01 as primary domain controller with DNS and DHCP / DC01 comme contrôleur de domaine principal avec DNS et DHCP
- DC02 as separate forest for bidirectional forest trust / DC02 comme forêt séparée pour la relation d’approbation bidirectionnelle
- Group Policy management and centralized administration / Gestion GPO et administration centralisée
- Windows 11 client machines for validation and testing / Postes clients Windows 11 pour les tests
- **Tech:** PowerShell, Windows Server, Active Directory

### ☁️ Azure Network Infrastructure Lab
Azure networking lab focused on secure connectivity, segmentation, and hybrid-ready design.  
Lab réseau Azure orienté connectivité sécurisée, segmentation et design hybride.

- Virtual Networks, NSGs, routing, and network design
- Azure Firewall, VPN Gateway, and hybrid connectivity concepts
- Architecture documentation and implementation notes / Documentation d’architecture et notes d’implémentation
- **Tech:** Azure, PowerShell, Terraform

### 🔄 Hybrid Identity and Migration Lab
Hybrid identity environment integrating on-premises and Microsoft cloud services.  
Environnement d’identité hybride intégrant les services on-premises et Microsoft cloud.

- Entra Connect for synchronization / Entra Connect pour la synchronisation
- Azure Arc for hybrid server visibility / Azure Arc pour la visibilité hybride des serveurs
- Windows Admin Center for centralized server management / Windows Admin Center pour la gestion centralisée
- Identity-focused lab work aligned with SC-300 / Lab orienté identité en lien avec SC-300
- **Tech:** Microsoft Entra, Azure Arc, PowerShell, Windows Server

### 🧪 Deployment and Services Lab
Multi-service infrastructure lab covering deployment and support services.  
Lab d’infrastructure multi-services couvrant le déploiement et les services de support.

- WDS, MDT, and ADK deployment services
- IPAM and DHCP service management / Gestion IPAM et DHCP
- File services and server administration roles / Services fichiers et rôles d’administration serveur
- Cluster and virtualization components hosted on lab infrastructure / Composants cluster et virtualisation
- **Tech:** Windows Server, WDS, MDT, Hyper-V, VMware vSphere
